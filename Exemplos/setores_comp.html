Setores Compartilhados

Explicativo sobre o que são, sua utilização e exemplos de códigos.


Seletor de Atributo

O seletor de atributos é um padrão que permite escolher e estilizar elementos HTML com base na presença, no valor ou em parte do valor de um atributo.
Exemplo:[title] { color: blue; } (Seleciona todos os elementos que têm o atributo title).

Seletor Descendente

O seletor descendente é um combinador representado por um espaço em branco ( ) entre dois ou mais seletores, usado para aplicar estilos a um elemento que está dentro de um elemento ancestral.
Exemplo:.container p {
color: blue;
}

Seletor Filho Direto

O seletor Filho Direto seleciona apenas os elementos que são filhos imediatos do primeiro elemento. Se o elemento estiver "escondido" dentro de outra tag interna, ele é ignorado.
Exemplo:.menu > li {
font-weight: bold; /* Só os itens principais ficam em negrito */
}

Seletor Adjacente Direto

O seletor Adjacente Direto seleciona o elemento que vem imediatamente depois de outro, desde que ambos tenham o mesmo elemento pai (sejam irmãos).
Exemplo:h1 + p {
font-size: 1.2rem; /* Só o parágrafo grudado no h1 muda */
}

Seletor de Irmãos Gerais

O seletor de Irmãos Gerais seleciona todos os elementos que vêm depois de outro, desde que compartilhem o mesmo pai. Não precisa ser o vizinho imediato.
Exemplo:.aviso ~ p {
color: red; /* Todos os parágrafos após o .aviso ficam vermelhos */
}

Seletor de Pseudoclasse

É usado para estilizar um elemento dependendo do seu estado ou de sua posição na página. Ele usa apenas um dois-pontos (:)
Exemplo:.meu-botao:hover {
background-color: green; /* O botão fica verde ao passar o mouse */
}

Seletor de Pseudoelemento

É usado para estilizar uma parte específica de um elemento, ou até adicionar conteúdo visual antes ou depois dele através do CSS. Ele usa dois dois-pontos (::)
Exemplo:.destaque::first-letter {
font-size: 3rem;color: purple; /* Deixa apenas a letra "E" gigante e roxa */
}
